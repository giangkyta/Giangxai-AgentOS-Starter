# Định nghĩa hoàn thành

Mỗi loại kết quả (bài Facebook, bài web, kịch bản video…) có **một file** ở đây, nói thế nào là **đúng ý chủ đội**.
`kiem-tra` kiểm theo file này trước tiên (`luat/worker.md`, điểm 0).

## Hai nguồn, nguồn nào thắng

1. **Skill chủ đội đã build lại** trong dự án: skill có định nghĩa hoàn thành riêng thì **skill thắng**.
   File ở đây chỉ trỏ tới skill đó và giữ những gì skill chưa có.
2. **Log từ các lần làm việc:** mỗi lần chủ đội sửa, chê hay quyết thay Agent, Super ghi một dòng vào mục "Đề xuất từ log"
   của file tương ứng. Dòng đề xuất **chưa phải tiêu chí**. Chỉ khi chủ đội duyệt (thường ở buổi rút kinh nghiệm tuần)
   mới chuyển lên mục "Tiêu chí". Khi chủ đội build lại skill, các dòng đã duyệt là đầu vào cho skill.

## Mẫu một file

- **Áp cho:** loại kết quả, dự án.
- **Skill gốc:** đường dẫn, và skill đã được chủ đội build lại chưa.
- **Tiêu chí:** mỗi dòng một điều, có ngày chủ đội chốt.
- **Bài mẫu đạt:** đường dẫn hoặc link, do chủ đội chọn.
- **Chủ đội ghét:** những điều không được có.
- **Đề xuất từ log:** chờ chủ đội duyệt.

Chưa có file cho loại kết quả nào thì Super hỏi chủ đội trước khi giao việc, hoặc ghi rõ trong phiếu là "chưa có định nghĩa hoàn thành".
