# Bài học

Mỗi tuần một file `YYYY-tuan-WW.md`, Super viết vào sáng Chủ nhật.

Mỗi file gồm: tổng số lần can thiệp trong tuần (so với tuần trước), các nhóm lỗi,
và đề xuất sửa cho từng nhóm. Thứ tự ưu tiên sửa: cấu hình piggery hay mẫu đội,
rồi danh sách kiểm của kiem-tra, rồi luat/, cuối cùng mới đến skill của dự án.
Chỉ sửa sau khi chủ đội đồng ý.
